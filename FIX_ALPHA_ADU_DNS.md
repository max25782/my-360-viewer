# Исправление DNS для alpha-adu.com

## Текущий статус

- ✅ `www.alpha-adu.com` - **Valid Configuration** (работает правильно!)
- ⚠️ `alpha-adu.com` - **Invalid Configuration** (нужно исправить)

## Что нужно сделать

Vercel расширяет IP диапазон, поэтому нужно обновить DNS записи для корневого домена.

### Шаг 1: Удалить старые A записи для корневого домена (@)

Перейдите к вашему регистратору домена и **удалите** следующие записи:

```
Type: A
Name: @
Value: 76.223.105.230
```

```
Type: A
Name: @
Value: 13.248.243.5
```

**Важно:** Эти старые записи нужно **удалить**, так как Vercel рекомендует использовать новые IP адреса.

### Шаг 2: Добавить новую A запись для корневого домена (@)

В вашем DNS провайдере **добавьте** следующую A запись:

```
Type: A
Name: @
Value: 216.198.79.1
```

**Примечание:** Это новый IP адрес из расширенного диапазона Vercel. Старые записи (`76.223.105.230` и `13.248.243.5`) продолжат работать, но рекомендуется использовать новый.

### Шаг 3: Поддомен www уже настроен правильно

`www.alpha-adu.com` уже имеет Valid Configuration, поэтому ничего менять не нужно. После исправления корневого домена, оба домена будут работать корректно.

## Проверка после изменений

Подождите 5-10 минут после изменений, затем проверьте:

```bash

# Должен вернуть: 216.198.79.1
# Старые IP (76.223.105.230, 13.248.243.5) могут еще присутствовать, но это нормально
```

1. Вернитесь в Vercel Dashboard

## Troubleshooting

### Если статус все еще Invalid:

1. **Проверьте, что старые записи удалены:**
   ```bash
   dig alpha-adu.com A
   # Проверьте, что старые IP (76.223.105.230, 13.248.243.5) удалены
   ```

2. **Проверьте, что новая запись добавлена:**
   ```bash
   dig alpha-adu.com A
   # Должен вернуть новый IP: 216.198.79.1
   ```

3. **Подождите дольше:**
   - DNS может распространяться до 48 часов
   - Обычно достаточно 5-60 минут

4. **Очистите DNS кэш:**
   ```bash
   # macOS
   sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
   
   # Linux
   sudo systemd-resolve --flush-caches
   
   # Windows
   ipconfig /flushdns
   ```
