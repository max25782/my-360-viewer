# Почему www.alpha-adu.com работает, а alpha-adu.com нет?

## Проблема

- ✅ `www.alpha-adu.com` - **Valid Configuration** (работает)
- ❌ `alpha-adu.com` - **Invalid Configuration** (не работает)

## Причина

Это проблема DNS настроек, а не кода. Код правильно обрабатывает оба домена.

### Что работает:

**`www.alpha-adu.com`:**
- В GoDaddy есть правильная CNAME запись:
  ```
  Type: CNAME
  Host: www
  Value: 97fd4c7e57d237f6.vercel-dns-017.com.
  ```
- Эта запись правильно указывает на Vercel
- Поэтому домен работает

### Что не работает:

**`alpha-adu.com` (корневой домен):**
- В GoDaddy есть старая A запись:
  ```
  Type: A
  Host: @
  Value: 76.223.105.230
  ```
- Но Vercel требует новую A запись:
  ```
  Type: A
  Host: @
  Value: 216.198.79.1
  ```
- Старая запись конфликтует с новой, поэтому домен не работает

## Решение

Нужно исправить DNS записи в GoDaddy:

### Шаг 1: Удалить старую A запись

В GoDaddy DNS настройках удалите:
```
Type: A
Host: @
Value: 76.223.105.230
```

### Шаг 2: Добавить новую A запись

Добавьте:
```
Type: A
Host: @
Value: 216.198.79.1
```

### Шаг 3: Обновить в Vercel

1. Подождите 5-10 минут после изменений DNS
2. В Vercel Dashboard нажмите "Refresh" рядом с `alpha-adu.com`
3. Статус должен измениться на "Valid Configuration"

## Проверка DNS

После изменений проверьте:

```bash
# Проверьте корневой домен (должен вернуть новый IP)
dig alpha-adu.com A
# Должен вернуть: 216.198.79.1

# Проверьте www (должен работать как и раньше)
dig www.alpha-adu.com CNAME
# Должен вернуть: 97fd4c7e57d237f6.vercel-dns-017.com.
```

## Почему код работает правильно

Код уже правильно обрабатывает оба домена:

```typescript
// Код автоматически определяет основной домен
hostname = "www.alpha-adu.com"
→ domainParts = ["www", "alpha-adu", "com"]
→ mainDomain = "alpha-adu.com" (последние 2 части)
→ используется логотип для alpha-adu.com: /logo2.jpeg
```

Оба домена (`alpha-adu.com` и `www.alpha-adu.com`) будут показывать один и тот же логотип после исправления DNS.

## После исправления

Когда DNS будет исправлен:
- ✅ `https://alpha-adu.com` будет работать
- ✅ `https://www.alpha-adu.com` будет работать (уже работает)
- ✅ Оба будут показывать логотип `/logo2.jpeg`
- ✅ SSL сертификат будет выдан автоматически

## Важно

Проблема **НЕ в коде**, а в DNS настройках. Код уже правильно обрабатывает оба домена. Нужно только исправить DNS записи в GoDaddy.
